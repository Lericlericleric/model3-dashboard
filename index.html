Game Lab — illustrative Monte Carlo

Enter projected points and standard deviations for both teams. The browser simulates independent normal-distributed scores and rounds them to nonnegative integers. This is a demonstration, not a calibrated sport-specific forecasting engine.

Model assumptions

Score distributions are independent, so real-world correlations, overtime, scoring increments, injuries, possession effects, and lineup changes are not modeled. Use this to understand mechanics, not to price real bets.

Data & backup

Records are stored in this browser's local storage, not in an online account. iPhone Safari can remove site data, and your data does not automatically synchronize across devices. Export backups regularly.

Never upload personal betting records to a public GitHub repository. Hosting the app's source code publicly is different from publishing your private browser data.
